# Changelog

## 1.0.0 — 2026-08-30

- Ratified the canonical flat crown/lotus mark for public web surfaces.
- Added framework-neutral light/dark/system semantic tokens.
- Added accessible action, presence, success, pending, blocked, and evidence states.
- Added typography, fluid type, spacing, radius, density, motion, forced-colors, imagery, and voice contracts.
- Added a machine-readable manifest, responsive specimen, migration notes, package exports, and deterministic validation.
- Deprecated the independent legacy `ui/*.css` token interpretations in favor of `web/profile.css`.
